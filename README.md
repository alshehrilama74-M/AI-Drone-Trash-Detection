# AI-Drone-Trash-Detection
AI-powered real-time waste detection and counting using YOLOv8, Python, OpenCV, and a DJI Tello drone

Overview: An AI-powered waste detection and counting system developed using a Tello drone and YOLOv8. The project aims to support environmental sustainability and Saudi Vision 2030 through intelligent waste monitoring.


Features:
1-Real-time waste detection using YOLOv8.
2-Object tracking and unique waste counting.
3-Live video streaming from a Tello drone.
4-Annotated video recording and visualization.

Technologies Used : Python ,YOLOv8 ,OpenCV ,DJI Tello Drone ,DJITelloPy.


How It Works :
1-The Tello drone captures live video.
2-YOLOv8 analyzes the frames to detect waste.
3-Object tracking assigns IDs to detected objects.
4-The system counts unique tracked items.
5-Results are displayed and saved as an annotated video.


Project Results : The system was demonstrated using a Tello drone and a laptop camera to detect and count waste items.


Future Improvements :
1-Municipality alert integration.
2-GPS-based waste location tracking.
3-Web dashboard for monitoring results.
4-Improved detection accuracy and drone camera quality.



This project explores how AI and drones can support environmental sustainability and smarter waste monitoring.
