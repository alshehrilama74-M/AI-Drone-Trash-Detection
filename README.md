# AI-Drone-Trash-Detection
AI-powered real-time waste detection and counting using YOLOv8, Python, OpenCV, and a DJI Tello drone
Overview

An AI-powered waste detection and counting system developed using a Tello drone and YOLOv8. The project aims to support environmental sustainability and Saudi Vision 2030 through intelligent waste monitoring.

Features

Real-time waste detection using YOLOv8.

Object tracking and unique waste counting.

Live video streaming from a Tello drone.

Annotated video recording and visualization.

Technologies Used

Python

YOLOv8

OpenCV

DJI Tello Drone

DJITelloPy

How It Works

The Tello drone captures live video.

YOLOv8 analyzes the frames to detect waste.

Object tracking assigns IDs to detected objects.

The system counts unique tracked items.

Results are displayed and saved as an annotated video.

Project Results

The system was demonstrated using a Tello drone and a laptop camera to detect and count waste items.
